METHOD

Given key + chord + melody → piano

01

Condition

Each complete window contains the active key, beat-aligned chord progression, and melody. The reference piano is excluded from the prompt.

02

Generate

The model samples piano events autoregressively with the published REMI-style setup: temperature 1.2 and probability-weighted top-k 5.

03

Decode

Generated REMI+ events are decoded into MIDI, then presented beside the melody, chord guide, and held-out reference for direct comparison.

MODEL SNAPSHOT

Qwen3-style symbolic music decoder

The model was expanded from the trained melody-to-piano checkpoint, then fully fine-tuned on POP909 + POP909-CL. This page reports raw, unconstrained sampling—including structural failures—instead of hiding them.
