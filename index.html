METHOD

Given melody → piano

01

Condition

The complete melody condition window is serialized first in REMI+ tokens. No ground-truth piano target is included in the prompt.

02

Generate

The model samples piano events autoregressively using temperature 1.0, top-k 20, and top-p 0.95.

03

Decode

Generated REMI+ events are decoded into a piano MIDI and combined with the original melody for direct listening.

MODEL SNAPSHOT

Qwen3-style symbolic music decoder

These samples were generated by the function-preserving depth-expanded model before additional 150M training. All generations reached the 2,048-token context safety ceiling.
